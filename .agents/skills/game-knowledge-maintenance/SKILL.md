name: game-knowledge-maintenance
description: Integrate evidence-backed reusable knowledge into an enabled project wiki, or inspect its consistency within a bounded scope; excludes product decisions and source migration.
---

## Role and inputs
Own the wiki delta, not source documents or run status. Read the project knowledge settings, authorized page scope, source revisions and returned findings. Use the [knowledge contract](../game-task-planning/references/knowledge-contract.md). Missing or disabled configuration does not authorize creating a wiki.

## Procedure
1. Read the configured index and relevant pages. Confirm which claims are still supported by current sources; separate intended behavior, observed behavior and unresolved disagreement.
2. For an authorized update, revise existing explanations first. Create a page only for a reusable topic that does not already have a home. Preserve source artifacts and link exact evidence instead of copying raw logs or entire task records.
3. Mark confirmed facts, approved decisions, hypotheses and unresolved conflicts distinctly. Replace superseded explanations without erasing the evidence trail. Update the existing index when page membership or its summary changes.
4. Use the existing single-writer/isolation contract. Recheck input revisions before applying the delta; changed inputs return to the owner for reconciliation. A read-only query or consistency review returns findings without writes.
5. Verify changed claims against their sources and run the configured document checks. Return changed pages, sources/revisions, verification limits and applied/no-change/deferred/blocked status. The supervisor owns completion classification.

## Output and stop
Use the knowledge-delta row in the [artifact contract](../game-task-planning/references/artifact-contract.md). Stop when the bounded delta and checks are complete; unrelated stale pages become deferred observations, not additional work. Do not invent approval, resolve product conflicts, or migrate an existing wiki.

Apply the [shared role and independent verification contract](../game-task-planning/references/role-contract.md).
