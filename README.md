## 실행

Windows에서는 저장소 루트의 `run-game.cmd`를 더블클릭하면 된다. 스크립트가 자신의 위치를 게임 경로로 사용하므로 어느 폴더에서 시작해도 된다. LÖVE 11.5가 `C:\Program Files\LOVE`에 설치되어 있어야 한다.

```powershell
.\run-game.cmd
.\run-game.cmd --smoke
& 'C:\Program Files\LOVE\lovec.exe' . --test
```

시험 실행기는 core/session/integration 세 파일을 모두 실행한다. 예외 또는 suite의 실패 종료 요청이 하나라도 있으면 프로세스 종료 코드1을 반환하고, 모두 성공하면0을 반환한다. 같은 suite의 뒤늦은 성공 요청은 앞선 실패를 지우지 않는다.

개발 변경은 콘텐츠 정의, 순수 규칙 계산, 저장 검증, 게임 연결, 화면 표시의 책임을 따라 확인한다. 상태를 읽는 미리보기와 조회는 저장하거나 실행 상태를 바꾸지 않는다. 정상 동작뿐 아니라 취소·저장 실패·동일 후보 재시도·완료 후 권리 확정을 계약별 테스트로 확인한다. 이름과 오류/완료 반환값은 한 의미를 전달하도록 유지하고, 입력·전투·세션의 소유권을 넘는 숨은 변경을 피한다. 작성·리뷰 시 함수 분할은 의미·불변식 경계와 탐색 비용으로 판단하며 길이/복잡도 점수만으로 PASS하지 않는다. 주석은 이유·계약·제약을 설명하고 모호한 이름/API를 대신하지 않는다.

PowerShell에서 저장소 밖에서 직접 실행할 때는 `& 'D:\github\defense-roguelike\run-game.cmd'`처럼 스크립트의 전체 경로를 지정한다. `love.exe .`의 `.`은 현재 작업 폴더이므로 다른 폴더에서 실행하면 게임을 찾지 못한다.

- 마우스 좌클릭: UI 선택/확정, 타워 선택 뒤 지도 칸 배치
- 상점의 `보유 관리`: 보유 타워 또는 설치 모듈을 고른 뒤 실제 지불액·환급액·소멸 효과를 확인하고 `판매 확인` 또는 `전체 취소`
- 배치 타워 `무료 회수`: SHOP/PREPARE에서 같은 인스턴스와 패치를 유지한 채 미배치 상태로 되돌림. COMBAT에서는 사용할 수 없음
- 수용량 증가 모듈 판매: 판매 후 초과하는 수만큼 현재 배치 타워를 정확히 선택해야 모듈 판매와 회수가 한 번에 저장됨
- `압축 제어(M06)` 구매: 구매 뒤 줄어드는 수용량만큼 배치 타워를 정확히 선택해야 확인할 수 있으며, 회수된 인스턴스와 부착 패치는 그대로 보존됨
- 패치 구매/상품 리롤: `부품 환급(M29)`은 정가·환급·실지출과 방문당 사용 횟수, `탐색 지원(M30)`은 명목가·할인·실지불과 다음 가격을 영수증으로 표시
- PREPARE의 `모듈 상태`: 장착 모듈의 현재 적용 조건, 수용량·정산 예상, 성장 현재/다음 값과 판매·새 판 초기화 조건을 확인. W15는 일반 정산과 `현장 학습(M37)` 성장이 없음을 별도로 표시
- 우클릭 또는 `Esc`: 판매/구매/새 판 확인 → 보유 관리 상세 → 기본 화면 순으로 현재 한 계층 취소, 보스 규칙 닫기, 현재 타워 선택 취소
- `P`: 전투 수동 일시정지/해제, `1`/`2`: 1배속/2배속
- 포커스를 잃으면 전투가 정지하며 돌아온 뒤 자동 재개하지 않는다.
- 보유 타워가 6기를 넘으면 인벤토리의 `이전`/`다음`으로 페이지를 이동한다.
- SHOP/PREPARE/RESULT의 `해금 조회`: `포탑`/`예치금`/`여유`/`비상`/`중가`/`자산`/`혼합`/`고급`/`균등`/`공용`/`예비`의11탭에서 영구 해금 조건·현재 권리·이번 판 후보·현재 상품 여부를 확인한다. 조회에서 `Esc`/우클릭으로 돌아올 수 있다.

예치금(M28)은 **새로운 W03–W14 일반 생존 완료의 보상 적용 전 골드가 20G 이상**이면 영구 해금된다. 완료 저장과 readback 확인 뒤 확정되며, 현재 판의 후보와 상품은 그대로이고 다음 새 판부터 시작 24종에 M28을 더해 추첨한다. 무료 지급이나 등장 보장은 없다. M28은 중급 12G이며 설치한 상태에서 일반 생존 정산 전 골드 5G당 이자 1G, 최대 4G를 지급한다. W01/W02와 20G 미만에서도 설치 효과는 적용되지만 W15·패배에는 이자가 없다. 기본 보상이나 다른 모듈 수입이 같은 정산의 이자를 늘리지는 않는다. 판매하면 이자는 0이며, 획득 제외 기록과 영구 해금 권리는 유지된다. 상품·모듈 상세는 현재 이자 예상과 상한을, 정산 영수증은 보상 전 골드와 실제 이자를 표시한다.

여유 회로(M43)는 **W03–W14 일반 생존 완료에서 장착 모듈1개 이상·실제 빈 모듈 슬롯2개 이상을 전투 내내 유지**하면 영구 해금된다. 현재 전투 중 모듈·슬롯 수를 바꾸는 행동이 없으므로 확인된 전투 시작 저장 상태로 유지 조건을 판단한다. M28과 조건을 독립 평가하고 동시 성립하면 같은 완료 저장에서 확정한다. 현재 판 풀은 유지하며 다음 성공한 새 판의 시작24종에 확정된 M12/M14/M15/M16/M28/M31/M41/M42/M43/M46만 추가한다. M43은 중급12G, 장착 시 빈 모듈 슬롯당 배치 타워 피해 +12%, 최대 +36%이며 자신도 슬롯1개를 차지한다. 기존 모듈 피해 보너스와 합산한다. 구매·판매 미리보기는 실제 빈칸과 M43 피해의 변경 전후를 표시한다. 판매 후 M43 효과는0이고 영구 권리·이번 판 획득 기록은 유지된다.

비상 출력(M46)은 **새 W03–W14 일반 생존 완료에서 확정 전투 시작 HP1–5·이번 웨이브 누수0 또는 W09–W14 완료 HP20**이면 영구 해금된다. W01/W02·W15·패배·미완료·중복은 제외한다. M28/M43와 독립 평가하여 동시 권리도 한 완료 저장과 readback 뒤 확정한다. 현재 판 풀·상품·RNG는 유지하고 다음 성공한 새 판의 시작24종에 확정된 M12/M14/M15/M16/M28/M31/M41/M42/M43/M46만 더한다(최대34종). 중급12G·슬롯1개이며 장착한 상태에서 현재 HP1–5일 때 배치 타워 피해 +40%를 기존 모듈 피해 합에 더한다. HP0/6 이상·미장착·미배치의 효과는0이다. 누수 뒤 같은 tick의 공격과 전투 상세는 실제 현재 HP를 사용하며 발사된 탄환 피해는 발사 시 고정한다. 구매/판매 확인은 현재 HP와 활성·피해 보너스 전후를 표시하고 판매 후 영구 권리·획득 이력은 유지한다. 회복·패배 방지·무료 지급·등장 보장은 없다.

중가 연동(M41)은 **새 W06–W14 일반 생존 완료에서 서로 다른 중가 모듈2종 이상을 확정 전투 시작부터 완료 직전까지 유지**하면 영구 해금된다. W01–05·W15·패배·미완료·중복은 제외하며 과거 완료 기록에서 소급하지 않는다. 고가16G·슬롯1개이고, 자신을 제외한 장착 중가 모듈당 배치 타워 피해+8%p를 기존 모듈 피해 합에 더한다(최대32%). 기본4슬롯에서는 자신 외 중가3종의24%가 최대이며 다른 효과 복사·곱연산·영구 스탯 변경은 없다. 구매와 판매 확인은 중가 종류 수와 연동 피해의 전후를 보여 주며 판매 후 효과는0, 권리와 획득 기록은 유지된다. 열 모듈의 해금은 같은 완료 저장/readback 뒤 독립 확정하며 현재 판 풀·상품·RNG는 유지한다. M41을 포함한 동시 알림의 `해금 상세`는 11탭 조회에서 각 전체 조건·효과·권리·현재 판 제외·다음 판 후보를 보여 준다.

자산 연동(M42)은 **새 W09–W14 일반 생존 완료에서 장착 모듈의 실제 기록 지불액 합40G 이상을 전투 내내 유지**하면 영구 해금된다. 정가·환급·현재 골드·리롤/타워/패치 지출로 추정하지 않으며 과거 완료에 소급하지 않는다. 고가16G·슬롯1개이고, 자신 제외 장착 지불4G당 배치 피해+2%p를 내림하여 기존 모듈 피해에 합산한다(최대30%p). 현재 판 풀은 동결하고 다음 성공한 새 판만 확정 권리를 후보에 추가한다. 거래 확인은 중가/자산/빈칸/비상 효과의 실제 전후, 지불·환급·권리·이력·정확 회수를 표시하며 취소·저장 실패에는 실행 상태를 유지한다. 유효한 비정가 기록은 그대로 보존하므로 정상 가격 신규 구매의 상한과 구분한다.

저격 포탑(T05)은 W05를 생존 완료해 W06에 도달하면, 전격 포탑(T06)은 W15 최종 보스를 처치해 승리하면 영구 해금된다. 결과 저장 확인 뒤에 확정되며 **다음 새 판부터** 상점 후보에 들어간다. 현재 판의 상품 풀은 바뀌지 않고, 후보 포함이 실제 상점 등장이나 무료 지급을 보장하지는 않는다. 저격은 12G·피해60·3초 간격·사거리5, 전격은 12G·피해14·1.2초 간격·사거리3이며 같은 명중 사건에서 최대 두 번 연쇄한다.

타워 판매 환급은 실제 지불액의 절반을 내림하며 무료 시작 타워는 0G다. 타워 판매 시 결합 패치는 소멸하고 환급되지 않는다. 모듈 판매 뒤에도 해당 종류는 이번 판의 획득 완료 상태를 유지하므로 다시 등장하거나 재획득되지 않는다.

저장은 LÖVE save directory의 두 세대 `save-a.json`/`save-b.json`에 기록되고 SHA-256 readback이 성공한 뒤에만 거래·회수·전투 시작·완료가 화면 상태가 된다. 저장 실패 화면에서는 이전 정상 저장을 유지한 채 `저장 재시도` 또는 미저장 변경 유실 경고가 있는 `안전 종료`를 선택한다. 전투 시작 저장을 재시도해 성공하면 같은 웨이브의 전투가 시작되며, 반복 실패 중에는 전투를 진행하지 않는다.

현재는 코드 기반 retro-kitchen 기능 UI다. 콘텐츠 정의에서 W01–W15와 최종 보스 규칙을 읽어 표시하며, 상점 상품은 새 판에 동결된 포탑·패치·모듈 풀과 Park-Miller seed로 재현 가능하게 뽑는다. `DR-MOD-I16-r1`, `DR-MOD-I12-r1`, `DR-MOD-I14-r1`, `DR-MOD-I15-r1`, `DR-MOD-I42-r1`, `DR-MOD-I41-r1`, `DR-MOD-I46-r1`, `DR-MOD-I43-r1`, `DR-MOD-I28-r1`, `DR-TOWER-U2-r1`, `DR-MOD-S24-r1`, `DR-RUN-002-r1`, `DR-SLICE-001-r2` 기존 판은 당시 풀·상품·RNG·진척을 유지한 채 현재 버전으로 읽는다. I28/I43/I46 저장의 기존 M28/M43/M46 권리를 보존하고 해당 이전 버전에 없던 이후 모듈 참조는 거부한다. 기존 포탑 해금 복원 규칙과 R7 저장 불변 조건은 유지한다. 과거 골드·진척·완료 기록에서 M12/M14/M15/M16/M28/M31/M41/M42/M43/M46을 소급 해금하지 않으며, 로드 자체는 원본 파일을 쓰지 않는다. 다음 실제 저장에서 현재 버전을 기록한다.

### I15/M15 혼합 개조

새 W06–W14 일반 생존 완료에서 서로 다른 ID 패치3개인 같은 타워1기를 확정 시작부터 완료 직전까지 배치하면 M15가 영구 해금됩니다. 늦게 설치한 타워, 패배·미완료·보스·중복 완료는 제외합니다. LOAD 자체로 과거 완료를 추정하지 않으며 복원 뒤 새 유효 전투는 인정합니다. 혼합 개조는 중가12G/슬롯1개이며 해당 배치 타워의 기존 모듈 속도 합에20%p를 더합니다. 다른 타워와 같은 패치ID 중복 적용의 기존 효과는 유지합니다.

해금은 한 완료 checkpoint의 readback 성공 뒤 공개하고 현재판 후보·상품·RNG를 유지합니다. 다음 성공 NEW_RUN의 후보만 기본24+획득10종(최대34)이며 무료 지급이나 등장 보장은 없습니다. 판매 뒤 영구 권리/그 판 획득 이력은 유지합니다. 조회11탭, 관리 상세와 거래 draft에서 실제 선택 타워의 고유 패치 수·속도·기여 전후 및 M41/M42/M43 변화를 확인할 수 있습니다.

관측/시작 증명은 Rules의 순수 함수, 제안과 실제 선택 연결은 Game, 저장 확정은 기존 Session/Save, 표시는 View가 소유합니다. missing/invalid 증거는 부분 정상 상태로 대체하지 않고 정상 비충족과 오류를 구분합니다. 취소는 draft만 해제하고 저장 실패는 같은 후보 bytes/generation을 재시도하며 성공 뒤에만 완료를 알립니다. 함수·상태·소유권·입출력/실패/취소/완료 계약과 named 검사의 연결을 리뷰하며 줄수나 점수만으로 리팩터링하지 않습니다. Lua dense 배열/고유ID/alias/receiver/여러 반환값과 Python native exit/timeout/cleanup은 실제 경로 기준으로 검증합니다.

### I14/M14 고급 정비

새 W09–W14 일반 생존 완료에서 패치 정가합21G 이상인 같은 타워1기를 확정 시작부터 완료 직전까지 배치하면 M14가 영구 해금된다. 같은 중가 패치ID3개도7+7+7=21G로 인정하며 고가 추첨은 필요하지 않다. 고가2개는10+10=20G로 실패하고 여러 타워의 값을 합하지 않는다. 늦은 배치·패배·미완료·보스·중복 완료와 LOAD 자체/과거 완료 추정은 제외한다. 복원 뒤 새 유효 전투는 인정한다.

고급 정비는 중가12G·슬롯1이며 장착 시 해당 배치 타워의 고가 패치 하나당 기존 모듈 피해 합에8%p를 더한다. 고가 중복도 각각 세고 미배치/미장착은0이다. 중가3개는 해금할 수 있으나 이 효과는0이며 고가2개에는16%p가 적용된다. 패치 정가와 실제 모듈 지불/환급은 별개다. M15 속도와 패치 불이익·중복 및 피해 계산 층을 유지한다.

13개 역사 버전을 읽을 때 파일 쓰기와 I14 소급 해금은0이고 당시6권리인 I15도 보존한다. 현재 판 후보/상품/RNG는 동결하며 다음 성공 NEW_RUN만 기본24+확정10권리(최대34)를 재추첨한다. 구매/판매·정확 회수 미리보기는 실제 선택의 피해/M14 기여와 M15 속도, M41/M42/M43의 변경 전후를 보여 준다. 취소는 보유 상태를 유지하고 완료/거래는 한 checkpoint의 readback 성공 뒤 공개한다. 판매 후 권리·획득 이력은 유지하여 이번 판 재구매를 막는다. 고급 탭은 정확한 조건·효과·권리·이번 판 후보·현재 offer를 구분한다.

### I12/M12 균등 투자

신규 W06–W14 일반 생존 완료에서 배치3기 이상 모두 같은 양의 패치 개수(각1개 이상)를 전투 내내 유지하면 M12를 영구 해금한다. 동일 패치 ID와 중복 패치도 수량으로 센다. 시작3기×1개는 인정하고 시작2기 뒤 후기3기 및 후기 무패치4번째 배치는 제외한다. 이미 균등한3기에 같은 수량의 패치를 가진 후기4기를 추가하면 조건은 유지된다. 패배·미완료·보스·중복 완료·LOAD 자체/과거 완료 추정은 제외한다.

중가12G·슬롯1 M12는 현재 배치2기 이상 모두 같은 양의 패치 개수일 때 배치 타워의 모듈 사거리 합에25%p를 더한다. 해금3기와 장착효과2기를 구분하고 미배치 기여는0이다. 기존 패치 사거리·불이익·중복과 M14 피해/M15 속도 등 모듈 층은 유지한다. 실제 전투의 후기 배치와 같은 tick부터 효과/표시가 갱신된다. 구매·판매·패치·정확 회수는 실제 선택의 전후 사거리와 다른 모듈 연동을 표시하며 취소/저장 실패는 이전 보유 상태를 보존한다.

이번 판 후보·상품·RNG는 동결하고 다음 성공 NEW_RUN만 기본24+확정10권리(최대34종)를 재추첨한다. 무료 지급/등장 보장/장착 승계는 없다. ## I16/M16 공용 설계

I16은 신규 W09–W14 일반 생존 완료에서 배치 타워 전체의 서로 다른 패치 ID 5종 이상을 시작부터 완료까지 유지하면 M16 공용 설계를 영구 해금한다. 중복 ID는1종, 예비 타워는 제외한다. 고가16G·슬롯1 M16은 현재 배치 전체 패치 ID당 기존 모듈 피해 합에+3%p, 최대27%p를 더한다. 시작4종 뒤 늦은5번째 배치는 해금에서 제외하고, 이미5종 뒤 무패치/중복/새ID 예비 배치는 유지된다. 같은 완료 checkpoint의 readback 뒤 권리·알림을 공개하며 현재 판 풀·상품·RNG는 유지한다. 다음 성공 새 판만 시작24+확정10권리, 최대34종을 재추첨한다. 판매/패배 후 권리·이번 판 획득 기록은 보존하고 무료 지급·등장 보장·장착 승계는 없다.

M16 당시 검사에서는 정가 모듈 구성으로 같은 완료에서 신규8권리, 유효 보존 실지불20G+20G 구성으로 신규9권리가 가능하다. 검사는 지원 checkpoint에서 제어된 실제 Battle 완료 writer와 메모리 저장을 사용한다. 원본 웨이브 전체 생존·S00부터 특정 seed 경로·물리 입력·밸런스·정식 아트는 이 검사 결과로 확정하지 않는다.
