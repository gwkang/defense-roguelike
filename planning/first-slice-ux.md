## 1. 플레이 과업과 판단 근거

- confirmed: 적/경로/다음 웨이브 정보를 보고, 보유 타워 배치 및 상점 구매를 결정한다. 패치는 구매 즉시 적용·제거 불가이므로 효과와 대상을 미리 확인해야 한다(C02–04/D13).
- derived: 처음에는 경로와 보유2기, 상점에서 선택할 때는 돈·대상·변화값이 우선이다. 해금48종/무제한 미배치 목록을 상시 전부 표시하면 저해상도 전장을 가린다. 이는 정보량에 근거한 설계 판단이지 사용자 관찰 결과가 아니다.
- delegated: **전장 중심 + 한 개의 문맥 상세 영역**, 상점·도감은 필요할 때 여는 확장 목록으로 선택. 상세 영역은 적/타워/입구/모듈 중 현재 대상 하나만 표시한다.
- 대안: 모든 정보를 고정 패널로 동시에 배치하면 비교 이동은 줄지만 480×270에서 전장·문구 밀도가 과도하다. 모든 것을 모달로 열면 전장은 넓지만 배치/정보 비교를 반복해서 끊는다. 선택안은 전장 관찰을 유지하며 긴 내용만 별도 확장한다.

전투 중 상세 패널을 여는 것만으로 자동 pause하지 않는다. 플레이어가 pause를 선택해야 한다. 일반 Esc 동작은 최상위 취소 가능한 선택/팝업부터 닫고, 없으면 pause 메뉴를 연다. pause 메뉴를 닫는 동작과 ‘재개’는 구분하고 종료 확인 취소는 pause로 돌아간다. 우클릭은 현재 조작 취소만, 게임 종료/판매를 실행하지 않는다. Space 등의 추가 단축키는 여기서 새로 정하지 않는다.

## 3. 구매·판매·예외 흐름

### 패치

상품 선택 → 효과/불이익·가격 확인 → 배치/미배치 타워 목록에서 대상 선택 → 전후 비교 → **구매 확정** → 저장 성공 시 적용 결과와 남은 칸 표시.

전후 비교는 피해·공격속도(회/초)·사거리(격자), 개수 `2/3→3/3`, 상시 모듈 반영값을 포함한다. 조건부 피해/추가 공격은 별도 설명으로 유지한다. 9개 패치의 내용을 유형 아이콘만으로 대체하지 않는다. 이미 패치3개인 대상도 보이되 선택 불가 이유를 표시한다. 취소는 상품·대상·돈·환급 전부 불변.

### 타워·모듈

타워 상품 선택 시 새 개체 구매임을 표시, 확인 후 미배치 목록에 들어간다. 모듈은 효과/가격/장착 후 슬롯을 보고 확인하면 즉시 장착. 이미 꽉 찬 일반 슬롯이면 판매가 먼저 필요함을 설명하며 자동 교체하지 않는다. 네거티브는 추가한도와 자체점유를 함께 보여준다.

모듈 구매 상세에는 원래 효과와 함께 **현재 배치에서의 적용 상태 / 빠진 조건 / 보유 개체로 준비 가능한지**를 표시한다. 조건은 카탈로그의 현재 상태 평가를 재사용하고 미래 전투 효율을 단정하지 않는다. 설치0기면 적용 타워 수 `0/0`을 억지 비율로 쓰지 않고 ‘설치된 타워 없음’으로 표시한다. 장착 후 투영값은 구매 미리보기임을 명시한다.

| 구매 전 예 | 보여줄 상태와 다음 행동의 의미 | 하지 않는 해석 |
| --- | --- | --- |
| M01, 기본2기만 보유 | ‘다른 종류와 상하좌우 인접 시 속도+20% / 현재 조건 미충족 / 다른 종류 타워 필요’ | 즉시 효과가 있다고 표시하지 않음. 미래 투자 구매는 허용 |
| M01, 냉각을 보유하나 미배치 | ‘보유 냉각을 다른 종류와 인접 배치하면 활성화 가능’과 현재 적용 개체 수 | 이미 가진 냉각을 새로 사야 한다고 안내하지 않음. 설치 한도·빈칸을 확인하기 전 배치 가능 확정 금지 |
| M17, 냉각 없음 / 보유 중 | 미보유면 ‘둔화 수단 필요’, 보유면 ‘냉각이 적을 둔화시킨 동안 피해+30%’; 사거리 겹침은 준비에서 확인 | 정지된 상점에 둔화 적이 없다는 이유로 항상 무효 판정하거나 현재 DPS+30%를 보장하지 않음 |
| M25 | ‘장착 유지 시 다음 생존 완료 정산+2골드’ | 구매 즉시+2로 표시하거나 전투 피해가 없으므로 무효라고 표시하지 않음 |

모듈마다 타워 수·조건부 상태·정산 사건 중 맞는 표현을 사용한다. 경고는 정보이며 돈/슬롯 등 기존 거래 제한 이외의 새 구매 금지·상품 필터를 만들지 않는다. 짧은 상태만 문맥 상세에 먼저 표시하고 긴 조건은 펼쳐 읽는다. 모든 조건을 전투 HUD에 상시 나열하지 않는다.

판매는 선택 개체의 실제 환급액과 사라질 패치/성장 정보를 확인한 뒤 확정. 모듈 판매로 수용량이 줄어 초과하면 전장에서 필요한 회수 대상을 표시·선택한 뒤 한 번에 거래 확정한다. 회수 선택 수/필요 수가 항상 보이며 취소는 전체 거래 취소다. 강제 판매·자동 삭제 없음.

### 오류와 중단

돈 부족/한도/경로·점유/저장 실패를 색상만으로 알리지 않는다. 상태명·짧은 이유와 허용되는 다음 행동을 표시한다. 오류는 성공 효과·골드 감소 애니메이션으로 표현하지 않는다. 저장 실패는 retry/미저장 손실을 설명한 종료만 제공하고 추가 구매·웨이브 시작을 막는다. 확정 버튼 중복 입력은 같은 transactionId로 처리한다.

## 4. 저해상도 정보량과 대상 고정

- 전장은 항상 핵심이지만 큰 상점/도감/결과 목록이 필요할 때는 확장 보기로 전환한다. 전투 도감은 수동 pause 상태에서 열어 상세 설명을 읽을 수 있게 한다. 관찰 패널은 전투를 자동 멈추지 않는 규칙과 구분한다.
- 모듈 장착 요약은 현재슬롯/한도·개별아이콘, 선택하면 효과·성장 현재/최대·조건·판매 손실·초기화 시점·다음 정산 예상치를 표시한다. 예상치는 현재 상태를 가정한 값임을 알리며 확정 보상과 구분한다.
- 48종 도감은 스크롤 목록+선택 상세. 효과/가격/조건/최소 완료번호/판 진척/다음 판 적용을 읽을 수 있어야 한다. I46의 대안 두 개를 생략하지 않는다. 한 번에48종 전체 내용을 축소 표시하지 않는다.
- 무제한 미배치 타워는 스크롤, 같은 종류라도 개체 단위로 별도 선택. instanceId에 기반한 짧은 구별표시와 패치 수를 사용한다. 종류별 합쳐진 수량만으로 패치 대상을 고르지 않는다.
- 상세 선택은 instanceId에 고정한다. 리스트가 재정렬돼도 같은 행 인덱스의 다른 타워를 구매 대상으로 바꾸지 않는다. 대상 판매/삭제 등으로 무효가 되면 선택 해제와 이유 표시.
- 입구 목록도 스크롤 가능, A/B 두 개를 고정 그리지 않는다. 경로 강조는 선택 입구를 식별자/선 형태/명도 등으로 함께 구별, 색상만 의존하지 않는다. 그림을 가리는 강조는 관찰 후 끌 수 있다.
- 마우스 wheel은 포인터 아래 목록만 스크롤. 패널 클릭이 뒤 전장 배치로 전달되지 않으며, letterbox 바깥 클릭도 배치하지 않는다. 확정 후 눌린 버튼 상태/선택 변경이 확인 가능해야 한다.
- 정확한 픽셀 영역·폰트 크기·최대 행수·반응형·히트박스·최종 카피는 screen-spec 소유의 OPEN 사항이다. 기능 프로토타입은 임시 기하를 명시해 시험할 수 있으나 정식 화면 준비 완료로 선언하지 않는다. 기존32×48 타워 아트가 논리1칸보다 커 보이더라도 배치 면적을 늘리지 않는다.

### 선택한 패치 아트와 정보의 역할 분리

최신 PATCH-AD-001 r7의 피해=몸통 앞판, 속도=상단/도구 사선, 사거리=하단 이중 받침 방향을 소비한다. 전장 표현은 패치 합산 후 양수인 강화 항목의 요약이며, 정확한 패치 이름·중복 개수·순수치·불이익은 선택 상세가 맡는다. 순합계0/음수를 양수 강화처럼 표시하지 않는다. 표현 강도/임계값·최종 픽셀 제작은 아트 소유이며 여기서 새로 결정하지 않는다.

선택 강조는 instanceId에 대응하고, 실제 사거리는 그때의 능력치로 계산한 범위 표시를 사용한다. 장식 받침 고리를 사거리 경계로 쓰지 않는다. 투사체/피해 이펙트와 겹쳐도 선택·입구 경로·범위 정보에 접근할 수 있어야 한다. 일반/밀집 장면에서 강화 찾기와 같은 종류 개체 선택, 상세 불이익 읽기를 [OBS05](first-slice-spec.md#61-리뷰-위험을-판별할-후속-관측)로 검증한다. 현재 아트 선택은 실제 전투 판독성 통과가 아니다.
