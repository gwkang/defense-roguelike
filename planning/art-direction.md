## 확정한 방향

| 항목 | 현재 기준 |
| --- | --- |
| 테마와 유머 | 음식들이 입으로 들어오는 것을 막는 다이어트 소재의 방어전. 지켜야 할 입은 음식을 반기는 상황적 위트 |
| 톤앤매너 | 조합·배치 전략을 즐기는 플레이어를 위한 레트로 키친/식당. 어두운 사실적 전쟁 표현과 유아적인 파스텔 핑크 중심 표현은 대체 |
| 색과 정보 우선순위 | 크림·먹색·차분한 청록/세이지, 머스터드 강조. 음식과 전투 효과에 높은 채도를 주어 경로·적·타워가 먼저 읽히도록 함 |
| 해상도 | 내부 480×270, 16:9. 1920×1080에서는 nearest-neighbor 4배 확대, 논리 픽셀 하나당 4×4 화면 픽셀 |
| 적의 시각 구분 | 작은 도넛, 중간 젤리, 길쭉한 피자, 크고 묵직한 햄버거. 색뿐 아니라 크기·비율·실루엣으로 구분 |
| 진입과 출구 | 두 개의 적 진입로가 합류해 하나의 입 출구로 이어짐. 시안의 냉장고 A·배달 상자 B는 진입 위치를 보여주는 표현 |
| 전투 밀도 | 작은 음식들이 여러 줄로 몰려오고 합류 지점에 군집이 형성되는 고밀도 전투. 큰 음식은 작은 무리 사이에 드물게 섞음 |
| 방어 장치 | 포크·집게·선풍기·냉각 장치 등 생활용품에 기반한 익살스러운 형태. 시각 스킨만으로 신규 타워 규칙을 확정하지 않음 |
| 효과 방향 | 저해상도에서 읽히는 큼직한 픽셀 타격 효과, 반동·찌그러짐·탄성 복귀 등 개성 있는 반응. 실제 모션 타이밍은 후속 제작에서 결정 |

## 이전 결정과 경계

- 2026-09-29 패치 아트 방향 확정: 사용자가 조합 시안에 “좋아 이 방향으로 결정”이라고 응답하여 [부위별 강화 표현 revision 7 / PATCH-AD-001](patch-art-direction.md)을 선택했다. 피해=정면 구리빛 충격판, 공격 속도=상단 노란 사선·식기 광택, 사거리=하단 청록 이중 받침. 복합은 해당 표현을 함께 유지한다. 단일 시안v7/조합 시안v8이 현재 시각 기준이며 은박만으로 장착 유무를 표현한v6는 역사다. 아트 방향 확정과 실제480×270/게임런타임/정식에셋검증은 구분한다.

- 2026-09-29 모듈 아트 후속: 사용자 요청에 따라 [레트로 키친 소품 모듈 초안](module-art-direction.md)을 작성했다. M01–M08의 개별 사물 시안이며, 이전 외계 하이브리드 코어 방향을 대체하는 제안이다. 개별 시안의 사용자 선택·정식 에셋 승인은 아직 없다.

- 외계 침공/《우주전쟁》의 어두운 고해상도 아트와 외계 방송 테마는 현재 방향으로 대체한다. 이전 이미지와 선택 기록은 역사로 보존한다.
- 해상도는 앞선 사용자 “해상도 기준은 좋아”, 두 입구는 “적의 진입로가 2개가 되도록 수정해”, 높은 밀도는 두 차례 밀도 수정과 최종 선택이 근거다.
- `planning/design-baseline.md` v0.6의 D10 단일 입구 및 D20 기계 방어 시설/침입체 테마보다 위 사용자 결정이 최신이다. 해당 제품 기획 문서의 동기화는 이 아트 기록에서 완료한 것으로 주장하지 않는다. 14×10 격자, 고정 경로, 경로 위 배치 금지 및 다른 게임 규칙은 이 시안으로 임의 변경하지 않는다.
- 이번 이미지의 높은 밀도는 전투 중 적이 많이 쌓인 순간의 참고다. 제작 프롬프트의 약 80–100마리는 탐색 목표이며 최종 웨이브 수량, 동시 적 상한, 등장 간격, 적 속도·체력이나 성능 예산으로 확정한 값이 아니다.
- 《한 입만》은 현재 작업명이며, 정식 게임명·상표 결정은 별도다. HUD 값과 배치 수, 정확한 경로 좌표·격자 수·사거리 반경, 실제 적 개체 수는 생성 이미지에서 역으로 규칙화하지 않는다.
- 이 이미지는 480×270에서 직접 제작한 픽셀 원본이 아니다. 실제 정수배 픽셀 정합성, 글자 가독성, 모션, 전투 가독성·성능은 제작/런타임에서 확인해야 한다.
- 선택한 방향과 시안의 보존만 수행했다. 제품 구현·정식 품질 승인·새 커밋·푸시·배포를 뜻하지 않는다.
