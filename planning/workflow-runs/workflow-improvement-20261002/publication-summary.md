# 작은 변경 워크플로우 공개 범위 · 2026-10-02

사용자 ‘커밋 푸시하고 개선된 스킬은 공개 저장소에도 올려’에 따른 선택적 공개다. 프로젝트에는 작은 변경 활성화 delta, 정책/계약, 증거 도구와 회귀만 포함한다. 다른 실행의 게임 코드·기획·위키 및 기존 스킬 최신화/필수절차/언어별 개선은 이번 커밋에 섞지 않는다. 작업 트리의 해당 변경은 보존한다.

프로젝트 도구는 손상 PNG의 모든 chunk 길이/CRC·완전한 IEND와 실제 픽셀 디코딩을 확인한다. Pillow가 없으면 PNG 검증을 차단한다. smoke는 성공 완료표시가 정확히 한 번이고 FAIL/FAILED/ERROR가 없어야 한다. 작성자와 독립 리뷰어 `/root/boundary_fix_review`가 회귀30/30을 통과했다. 로컬 위키 출처128건과 original18/save2 보존도 확인했지만, 그 프로젝트 지식/생산 경로와 실행 원장/raw는 이 공개 범위 밖에 보존한다. 실게임·기기·시간 절감 증거가 아니다.

공개 스킬 묶음에는 프로젝트 선택형 small-change 계약과 캡처/명령 adapter 실패 검증 기준만 이식한다. 엔진·플랫폼·해상도·모듈·제품 정책·프로젝트 도구·실행 기록·위키·개별 모델 이름은 이식하지 않는다. 실제 공개 commit과 번들/설치 검증은 최종 보고에서 구분한다.
