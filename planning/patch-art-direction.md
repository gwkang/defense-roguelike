## 확정한 방향

사용자가 조합 시안에 **“좋아 이 방향으로 결정”**이라고 응답했다. 단일 강화 v7과 조합 v8의 **부위·큰 형태로 강화 항목을 구분하고, 복합 강화에서는 해당 표현을 함께 유지하는 방향**을 현재 기준으로 선택했다. 이는 아트 방향 확정이며 정식 에셋·실제 게임 크기·전투 가독성 검증 통과를 뜻하지 않는다.

| 강화 항목 | 선택한 표현 | 주 위치 |
| --- | --- | --- |
| 피해 | 큰 크림색 충격 문양이 있는 구리빛 판 | 몸체 정면 |
| 공격 속도 | 머스터드색 굵은 사선 띠와 식기의 방향성 광택 | 몸체 상단·식기 |
| 사거리 | 넓은 청록색 이중 원형 받침 | 몸체 하단 |

- 기본 수저통의 체크무늬, 식기 실루엣, 입체 명암과 레트로 키친 정체성을 유지한다.
- 피해+속도 / 속도+사거리 / 피해+사거리 / 세 항목 모두는 각 부위의 표현을 함께 사용한다. 조합을 이유로 별개의 타워나 단계별 크기로 바꾸지 않는다.
- 색뿐 아니라 위치와 큰 형태가 구분 수단이다. 작은 스티커나 공통 은박 효과만으로 강화 종류를 전달하지 않는다. 은박/광택은 보조 표현이다.
- 이 그림은 강화 항목 조합의 시각 기준이다. 새 희귀도·강화 등급·조합 보너스·장착 조건을 만들지 않는다. 같은 항목 중복을 작은 장식의 반복 개수로 표현하지 않는다.
- 전장 표현은 패치 합산 후 증가한 항목을 요약하고, 정확한 이름·개수·수치·불이익은 선택 상세에서 확인한다. 강화량별 표현 강도와 임계값은 아직 확정하지 않았다.
- 원형 받침은 사거리 강화의 표식이며 실제 사거리 범위를 그린 원이 아니다.

## 컨셉

패치는 **단색 사각 바탕 + 흰색 능력치 기호 한두 개**로 표현한다. 피해는 네 갈래 충격 모양, 속도는 오른쪽 꺾쇠, 사거리는 양끝 화살표다. 기본 보강은 기호 하나, 강한 특화는 같은 기호 반복, 복합 강화는 다른 기호 두 개를 사용한다. 기호 반복은 강화 성격을 표시하는 시각 규약으로, 2배 효과나 두 슬롯 점유를 뜻하지 않는다. 이것은 시각 문법이며 새 패치 계열이나 세트 규칙이 아니다.

모듈은 전역 슬롯에 놓이는 입체 주방 소품, 패치는 각 타워의 발밑에 붙어 다니는 작은 표식으로 구분한다. 모든 타워에 적용 가능한 추상 개조 표식이며, 타워 아트 본체를 가리지 않는 하단 표시줄을 제안한다. 실제 구현은 후속 작업이다.

## 전투 중 타워 표시

480×270 밀집 배치 원본 (`planning/workflow-runs/art-direction-20260928/patch-exploration/patch-pixel-v4-dense-480.png` · 로컬 전용 아트 탐색 자료·이번 공개 제외)

타워6개와 선택 상세가 있는 실제480×270 원본이다. 정확한4배 확대 (`planning/workflow-runs/art-direction-20260928/patch-exploration/patch-pixel-v4-dense-1920.png` · 로컬 전용 아트 탐색 자료·이번 공개 제외)는 새 디테일 없이 원본 픽셀을4×4로 복제한다. 그래픽은 가독성 검토용 임시 표현이다. 앞선1536×1024 생성 비교 이미지는 역사로 유지한다.

- 타워 하단20×9픽셀에 피해·속도·사거리 순서의5×5 기호를 배치한다. 패치 합산 보정이 양수인 항목만 표시해 **순 보너스 항목**을 알려준다. 순합계0/음수는 기호를 켜지 않는다.
- 기호 밑의3×2 작은 표시최대3개로 **실제 패치 장착 수**를 따로 보여준다. 피해 보강3개는 피해 기호1개+장착 표시3개, 복합 패치1개는 능력치 기호2개+장착 표시1개다. 기호를 장착 슬롯으로 해석하지 않는다.
- 무강화는 비어 있는 어두운 요약 바, 강화는 기호의 존재로 구분한다. 인접한 타워와 경로를 침범하지 않도록 타워 본체·요약·장착 표시를22×22셀 안에 넣는다. 전장에는 정확한 개별 패치ID를 표시하지 않는다.
- 구매 확정 시 장착 표시를 짧게 강조하는 모션은 제안으로 남는다. 현재 원본은 정지된 상태 검토이며 모션을 구현하지 않았다.
- 타워 본체와 역할 실루엣은 유지한다. 장식 증가만으로 강화 여부를 추측하게 하지 않는다. 상품 설명/선택 패널에서는 정확한 패치 이름·이득·불이익·최종 수치를 계속 제공한다.
- 일반·밀집·불이익·복합1개의4개 실제크기 정지 화면에서 중복3개/복합1개와2개/특화3개 합산을 표현했다. 세 기호와 개수 표시의 기술적 픽셀 배치를 검토하는 초안이며, 게임 엔진 실행·다른 타워 외형·움직이는 공격 이펙트·사용자 인식 시험은 아직 없다. 기호만으로 음수/0을 구분하지 못하는 한계는 선택 상세의 정확한 수치로 보완한다.

## 사용 표현 제안

- 구매 대상과 적용 전후 능력치를 확인한 뒤 확정하면 타워 장착 수 표시를 짧게 강조하는 모션을 제안한다. 확정 전에는 소비/적용된 것처럼 연출하지 않는다.
